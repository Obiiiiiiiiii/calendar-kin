Chat scanner (Phase 2)

Reads new chat messages and catches plannable future events the kin mentioned ("I've got that gig Thursday"), writing them to the calendar tagged mentioned. Chat is ground truth: a mentioned event displaces a clashing generated one.

Polling is adaptive to stay light on Kindroid's API: every {{ interval }} minutes while chat is active, doubling after each quiet check up to every {{ max_interval }} minutes. One new message snaps it back to the fast rate. The AI is only invoked when there are new messages, so quiet checks cost nothing.
